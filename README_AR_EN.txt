HONTEC 370 — v3.1.7

العربية
- ملفات التطبيق: index.html وmanifest.json وsw.js وجميع الأيقونات في نفس المجلد.
- للتجربة المباشرة بدون تثبيت: افتح HONTEC_370_Standalone.html بالمتصفح؛ يعمل بدون إنترنت.
- للنشر: ارفع محتويات المجلد إلى جذر المستودع وشغّل GitHub Pages أو استضافة HTTPS. احتفظ بأسماء الملفات وترتيبها كما هي.
- للتثبيت والاستخدام دون إنترنت: افتح رابط HTTPS مرة واحدة لتحميل ملفات التطبيق ثم استخدم إضافة إلى الشاشة الرئيسية عند إتاحتها.
- بعد استبدال نسخة قديمة على الاستضافة: أعد تحميل الصفحة، ثم اضغط «تحديث الآن» إذا ظهر.
- اللغة عربية/إنجليزية، والنتائج والمدخلات تُحفظ محليًا عندما يسمح المتصفح.
- تغيير زر سماحية 0.5 مم يعيد اختيار السليندر والتكرار إلى الوضع التلقائي.
- مقاس 75 مم، جاب 3 مم: مع السماحية 98T وتكرار 4؛ بدونها 124T وتكرار 5 بالقائمة الافتراضية.
- أرقام محيط السليندر قبل وبعد الديستورشن أسفل عناوينها، ومقاس الريبيت فوق نسبة الديستورشن.
- حُذفت الملاحظات أسفل النتائج ومقاس الاستيكر بعد الديستورشن وLabels per revolution.
- تصدير PDF بنفس بيانات ولغة قسم التفاصيل، والأرقام بجوار الأسماء، مع Layout.
- Material width waste بالمليمتر = عرض الخامة ناقص صافي عرض الاستيكرات، شامل الجابات والهوامش.
- Geometric area waste بالنسبة المئوية يحسب هالك المساحة الكلي.

English
- Keep index.html, manifest.json, sw.js and every icon together.
- Open HONTEC_370_Standalone.html for a self-contained offline trial.
- Upload the extracted files to the repository root and enable GitHub Pages or another HTTPS host.
- Visit the hosted app online once before offline use. Installation depends on browser support.
- Version 3.1.7 includes the latest tolerance, typography and PDF changes.
- The tolerance switch resets cylinder and around-count selections to Automatic.
- PDF values appear directly beside their labels. Width waste is in mm; geometric area waste remains a percentage.

V3.1.7: PDF and calculation details share all 15 rows and language. PDF embeds the same SVG layout as the app, with label numbers, dimension lines, CD axis and direction arrow.
